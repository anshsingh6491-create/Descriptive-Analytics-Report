# Retail Pulse Dashboard – IBM Cognos Analytics

## 📌 Project Overview
Retail Pulse is a data analytics project created using IBM Cognos Analytics. The project focuses on analyzing retail business data to understand sales performance, product demand, customer purchasing patterns, and overall business trends.

The dashboard presents important business insights through interactive visualizations and reports, helping users understand retail performance and make data-driven decisions.

## 🎯 Project Objectives
- Analyze overall retail sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing trends.
- Compare sales across different regions.
- Track key performance indicators (KPIs).
- Present meaningful business insights using charts and visualizations.

## 📊 Tools and Technologies
- **IBM Cognos Analytics** – Dashboard and report creation.
- **Retail Pulse Dataset** – Data source for analysis.
- **Data Visualization** – Charts, graphs, and KPI indicators.
